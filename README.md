# 🧱 Stack Rush
Web game about stacking blocks, simple prototype with some features, built with Vibe Coding.
---
## 🎮 Gameplay
Stack moving blocks as high as you can! Each placed block shrinks based on your accuracy — too far off and it’s game over. The goal is to build the tallest tower possible while keeping your timing sharp.
---
## 🧠 Features

- Perfect placements reset the block size  
- Game gets faster the longer you survive  
- Bonus block gives extra points when landed perfectly  
- Penalty block reduces points when landed wrong *(still buggy)*  
- Streaks reward consistent precision with effects and feedback  
- Tracks your best score locally in the browser  
- Built completely with HTML, CSS, and JavaScript - no engines  
- Works on desktop and mobile browsers (ig)

## 🚀 How to Play
1. Click (or tap) to place a moving block.  
2. Stack as precisely as possible.  
3. 2 Perfect placements can reset block size or trigger bonuses.  
4. Avoid penalty blocks — they’ll deduct points! (Buggy) 
5. Build your tower as high as you can before missing the stack.
6. there's an event called "gravity flip" which flips the whole game...
